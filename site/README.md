# MASHIKA — сайт художницы (версия 1.0)

Одностраничная витрина. Без сборки, без фреймворков и бэкенда: HTML + CSS + JS (~35 КБ).
Шрифты подгружаются с Google Fonts; без сети подставятся системные.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: первый экран, галерея, «О художнице», контакты |
| `style.css`  | оформление и адаптив |
| `main.js`    | анимация первого экрана, галерея, просмотр картины, курсор |
| `works.js`   | **список картин** — единственное место, которое нужно править при добавлении работ |

## Посмотреть локально

Достаточно открыть `index.html` двойным кликом в браузере.

## ⚠️ Что сейчас заглушка

- **Картины** — сгенерированные абстракции (`image: null` в `works.js`), названия выдуманы.
- **Контакты** — `USERNAME`, `70000000000`, `hello@example.com` в `index.html`, блок `#contact`.
- **Текст «О художнице» и цитата** — в `index.html`, блок `#about`.

## Как добавить настоящие фото

1. Положить фото в папку `site/img/` (JPG/WebP, ~1600 px по длинной стороне, до 300–400 КБ).
2. В `works.js` у нужной работы указать `image: 'img/имя-файла.jpg'`, поправить название, размер, год, статус.
3. `w` и `h` задают пропорции карточки — ставьте реальный размер холста в сантиметрах.
4. Цена: число в рублях (`price: 45000`) или `null` → «цена по запросу».
5. Статус: `available` — доступна, `reserved` — забронирована, `sold` — в частной коллекции (кнопка «Хочу эту работу» скрывается).

Поле `schema` в `works.js` — версия формата данных. `main.js` проверяет её и пишет ошибку в консоль браузера,
если версии разошлись. Менять только вместе с `WORKS_SCHEMA` в начале `main.js`.

## Как выложить в интернет (бесплатно)

- **Netlify Drop** — перетащить папку `site` на app.netlify.com/drop, ссылка появится сразу.
- **GitHub Pages** — публикует только корень репозитория или папку `/docs`, поэтому `site/` придётся
  вынести в отдельный репозиторий (или переименовать). Для старта проще Netlify.
