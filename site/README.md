# MASHIKA — сайт художницы (версия 1.3)

Домен: **mashika.art**

Одностраничная витрина. Без сборки, без фреймворков и бэкенда: HTML + CSS + JS (~45 КБ).
Шрифты подгружаются с Google Fonts; без сети подставятся системные.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: первый экран, галерея, «О художнице», контакты |
| `style.css`  | оформление и адаптив |
| `main.js`    | анимация первого экрана, галерея, просмотр картины, курсор |
| `works.js`   | **список картин** — единственное место, которое нужно править при добавлении работ |
| `404.html`   | страница «не найдено» (Netlify и GitHub Pages подхватывают её сами) |
| `og.jpg`     | превью ссылки в мессенджерах и соцсетях, 1200×630 (снимок первого экрана) |
| `apple-touch-icon.png` | иконка на домашнем экране телефона |
| `robots.txt`, `sitemap.xml` | для поисковиков |
| `CNAME`      | домен для GitHub Pages |

## Что умеет

- **Первый экран:** живые цветовые пятна тянутся за курсором; клик или касание оставляет мазок, который растворяется.
- **Галерея:** фильтр «Все / В наличии», 3D-наклон с бликом, появление при прокрутке.
- **Просмотр работы:** полный экран, листание стрелками, клавишами ← → и свайпом.
- **«Примерить в интерьере»:** картина над диваном 220 см в реальном масштабе (по `w`/`h` из `works.js`).
- **Пасхалка:** 5 быстрых кликов по большому слову MASHIKA показывают посвящение; ещё одно лежит в консоли браузера.

## Посмотреть локально

Достаточно открыть `index.html` двойным кликом в браузере.

## ⚠️ Что сейчас заглушка

- **Картины** — сгенерированные абстракции (`image: null` в `works.js`), названия выдуманы.
- **Контакты** — `USERNAME`, `70000000000`, `hello@example.com` в `index.html`, блок `#contact`.
- **Текст «О художнице» и цитата** — в `index.html`, блок `#about`.

## Как добавить настоящие фото

1. Положить фото в папку `site/img/` (JPG/WebP, ~1600 px по длинной стороне, до 300–400 КБ).
2. В `works.js` у нужной работы указать `image: 'img/имя-файла.jpg'`, поправить название, размер, год, статус.
3. `w` и `h` задают пропорции карточки — ставьте реальный размер холста в сантиметрах.
4. Цена: число в рублях (`price: 45000`) или `null` → «цена по запросу».
5. Статус: `available` — доступна, `reserved` — забронирована, `sold` — в частной коллекции (кнопка «Хочу эту работу» скрывается).

Поле `schema` в `works.js` — версия формата данных. `main.js` проверяет её и пишет ошибку в консоль браузера,
если версии разошлись. Менять только вместе с `WORKS_SCHEMA` в начале `main.js`.

## Как выложить в интернет (бесплатно)

- **Netlify Drop** — перетащить папку `site` на app.netlify.com/drop, ссылка появится сразу.
- **GitHub Pages** — публикует только корень репозитория или папку `/docs`, поэтому `site/` придётся
  вынести в отдельный репозиторий (или переименовать). Для старта проще Netlify.

## Домен mashika.art

В `index.html` прописаны `canonical` и `og:url` = `https://mashika.art/`, в папке лежит `CNAME`
(нужен только GitHub Pages; Netlify его игнорирует).

**Netlify (рекомендуется):** Site configuration → Domain management → Add a domain → `mashika.art`.
Netlify покажет точные DNS-записи; обычно у регистратора домена нужно добавить:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | IP балансировщика Netlify (показан в панели) |
| CNAME | `www` | `<имя-сайта>.netlify.app` |

HTTPS-сертификат Let's Encrypt Netlify выпустит сам после того, как DNS обновится (от минут до суток).

**GitHub Pages:** сайт должен лежать в корне отдельного репозитория (вместе с файлом `CNAME`);
у регистратора — A-записи `@` на адреса GitHub Pages и CNAME `www` → `<логин>.github.io`.

⚠️ Значения DNS указаны по памяти — сверяться с тем, что показывает панель хостинга.
