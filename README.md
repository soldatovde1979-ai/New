# SVO Docs Automation

Стартовый скелет проекта автоматизации документации. Полное описание системы — в [`spec.md`](spec.md), схема конфигурации и данных — в [`data.md`](data.md).

## Быстрый старт (заготовка)

```bash
pip install -e .
svo-docs generate
svo-docs check
```

> Проект находится на самом старте: команды CLI и логика сканирования — заглушки, см. раздел "Roadmap" в `spec.md`.
